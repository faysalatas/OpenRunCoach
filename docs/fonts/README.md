# Bundled fonts

Bricolage Grotesque (600, 700) and Inter (400, 500, 600) are bundled in `app/src/main/res/font/`. The app loads only local resources and requires no font provider or network access.

Source: [Google Fonts](https://github.com/google/fonts/tree/5bb28733cec313b63fbd415b574b5ae35c8aa8b8), revision `5bb28733cec313b63fbd415b574b5ae35c8aa8b8`. The adjacent source files record exact upstream URLs and original hashes. Both families use SIL Open Font License 1.1; unmodified license texts and copyright notices are included here. These licenses apply to the fonts, not to the app.

Static TTF instances were generated with FontTools by fixing the weight axis to the specified value and all other axes to the upstream defaults. No glyphs were removed.
