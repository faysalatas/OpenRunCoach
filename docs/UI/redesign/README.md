# Redesign reference

- `../../OpenRunCoach_REDESIGN_SPEC.md` is the spec. Read it first.
- `design-tokens.json` has every color and size in machine-readable form.
- `sources/*.dc.html` are the exact board sources (HTML + inline CSS). Read the markup for spacing, sizes and structure. They need the canvas runtime to render, so use the PNGs for looks.
- Add PNG exports here (`today-light.png`, `today-dark.png`, ...), one per board.
